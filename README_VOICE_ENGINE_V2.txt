IP WATCH 2.3.0 — VOICE ENGINE V2

Cambios:
- Cola de anuncios TTS en background.
- Deduplicación de frases repetidas.
- Un reintento automático ante error TTS.
- Estado persistente: IDLE / READY / QUEUED / SPEAKING / RETRYING / ERROR.
- Botón "Probar voz" en Automatización > Notificaciones.
- Indicador de estado y último evento de voz.
- La IP se pronuncia separando cada octeto con "punto".

Instalación:
1. Abre chrome://extensions
2. Activa Modo desarrollador.
3. Pulsa "Cargar descomprimida" y selecciona la carpeta EXTENCION.
4. En el popup abre Automatización y pulsa "Probar voz".
