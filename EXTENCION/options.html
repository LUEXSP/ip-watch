IP Watch v2.0 — Instalación local. Los cambios se guardan en el agente.
Conexión local
Debe coincidir exactamente con local_auth_token del archivo ip_watch_config.json.
API Keys
Obtén tu key gratis en abuseipdb.com/account/api
Obtén tu key en ipqualityscore.com/user/settings
0 = más permisivo, 1 recomendado, 2–3 más agresivo.
Usuario de la API de Scamalytics (sin captcha)
Obtén tu key en scamalytics.com/ip/api
StarVPN
Encontrá tu token en el panel de starvpn.com
Monitoreo
Con qué frecuencia el agente verifica si cambió la IP pública. Mínimo 30s.
Si el fraud score supera este valor, se dispara una notificación.
Cambio automático de timezone
Cambia la zona horaria de Windows según la IP detectada
Script al cambiar IP
El agente pasa las variables de entorno IPWATCH_NEW_IP y IPWATCH_OLD_IP. Dejar vacío para desactivar.
